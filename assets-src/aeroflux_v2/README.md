# AeroFlux machines v2 (Mekanism-style casing)

Eight machines, six tiers each, drop-in for `assets/aeroflux/`. Generated by `assets-src/tools/gen_machines_v3.py`.
Machines: flux_furnace, flux_grinder, alloy_smelter, flux_sawmill, flux_infuser, flux_enchanter,
flux_disenchanter, plant_grower. Tiers: copper (no suffix), iron, gold, diamond, netherite, fluxium.

| Folder | Contents |
|---|---|
| `models/block` | `<m>_base.json` (shared elements, parent `minecraft:block/block` so the item display transforms apply); `<m>[_<tier>].json` and `<m>_active[_<tier>].json` are texture-only children |
| `models/item` | `<m>[_<tier>].json`, a 3D block item whose parent is the block model |
| `items` | 1.21.4+/26.1 item definitions pointing at `aeroflux:item/<m>[_<tier>]` (26.1.2 only; older versions skip this folder) |
| `blockstates` | `<m>[_<tier>].json`, variants `facing=<n/e/s/w>,lit=<true/false>`; lit=true uses the `_active` model |
| `textures/block` | 32x32 faces: `<m>_{front,side,back,top,bottom}[_<tier>]`; `<m>_front_active[_<tier>]` is a 4-frame animation (+ .mcmeta) |
| `renders` | 128 px isometric icons of each machine, for the guidebook, JEI-style listings and docs |
| `shapes` | hit/collision boxes (all full cubes; the window recess is visual only) |

Wiring notes
- The blocks need a boolean `lit` property alongside `facing`. If tiers are one block with a tier stored in the
  block entity, use the copper files for the block model and swap in tier textures however the tier is exposed;
  if they are separate blocks, use the `_<tier>` blockstates and items.
- plant_grower: the model is a hollow chamber behind glass (front and both sides) with a soil floor and a
  grow-lamp roof and NO crop. The block entity renderer must draw the real planted crop at its real growth stage.
  It sets render_type translucent for the glass. Chamber interior (facing north): x 2.5..13.5, y 5..14, z 1.5..14.
- shared parts: `plant_grower_glass`, `plant_grower_inner`, `plant_grower_soil`, `plant_grower_lamp[_active]`.
