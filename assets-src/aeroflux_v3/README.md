# AeroFlux converters (same casing family and layout as aeroflux_v2)

flux_energy_converter (Flux -> FE), flux_ae_converter (Flux -> AE2 power), flux_stress_converter (Flux -> Create stress).
Six tiers each: copper has no suffix, then _iron, _gold, _diamond, _netherite, _fluxium. Generated by
`assets-src/tools/gen_converters.py`. Layout is identical to aeroflux_v2: models/block/<m>_base.json plus texture-only
children <m>[_<tier>].json and <m>_active[_<tier>].json, models/item, items (26.1), blockstates (facing + lit),
32x32 textures with animated <m>_front_active[_<tier>] (+ .mcmeta), shapes (full cubes).

- flux_stress_converter: the front has a 4x4 px open hole at x 6..10, y 6..10 (centered) through the front plate;
  the recess behind it is dark. Create draws the rotating shaft there. The cog around the hole is painted on the plate.
- Back faces: the energy converter has three copper output plugs, the AE converter a quartz-sleeved cable port.
