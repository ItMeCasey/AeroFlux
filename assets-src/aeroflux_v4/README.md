# aeroflux_v4: the next machine wave

Generated by `assets-src/tools/gen_new_machines.py` (`python gen_new_machines.py`). Design spec in
`CONCEPTS.md`. Same layout as `aeroflux_v2` and `aeroflux_v3`: copy `textures/`, `models/`, `blockstates/` and
`items/` into the mod's assets.

Blocks: flux_crafter, flux_purifier, moon_spawner, sky_controller, flux_blender, animal_breeder, flux_repairer,
flux_sifter, flux_magnet, sun_lamp, moon_lamp. Six tiers each (copper has no suffix).

- Machines have `facing` x `lit` blockstates, `<name>[_tier]` models, `<name>_active[_tier]` for lit, and an
  animated `<name>_front_active[_tier]` strip (4 frames, frametime 4).
- `flux_sifter` and `flux_magnet` have an open top (a pit). The pit floor texture is `<name>_tray[_tier]`, which
  shows the mesh color per tier on the sifter. The magnet's horseshoe is real geometry in the model.
- The lamps have only `lit` in the blockstate; the crystal is `<lamp>_crystal` and the animated
  `<lamp>_crystal_active`. They are drawn smaller than a full cube, but the shape file uses a full cube to keep
  them easy to place and click.
- `shapes/machine_shapes_v4.json`: all full cubes.
- No crop, mob or item is drawn in these textures. The moon spawner's eyes are painted art only.

Previews: `assets-src/preview_new_machines.png`, `preview_sifter_tiers.png`, `v4_fronts.png` (own renderer, not
Minecraft lighting).
